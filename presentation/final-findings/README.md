The deck presents Mini Gibson as a reproducible training and evaluation pipeline
for improving coding agents. It separates the completed v1 model evidence from
the successor compatibility preflight and does not present either experiment as
a production-ready model release.

The native chart on slide 4 remains editable. Speaker notes cite the repository
evidence behind each claim. Until the terminal evidence package exists, slide 5
is explicitly provisional. Its final compatibility counts will be regenerated
from
[`summary.json`](../../docs/evidence/mini-gibson-successor-2026-10-18/summary.json),
after the complete 456-receipt journal and manifest pass the evidence verifier.
