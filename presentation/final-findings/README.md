This deck presents Mini Gibson as a reproducible training and evaluation pipeline
for improving coding agents. It separates the completed v1 model evidence from
the successor compatibility preflight and does not present either experiment as
a production-ready model release.

The native chart on slide 4 remains editable. Speaker notes cite the repository
evidence behind each claim. Slide 5 reports the verified terminal preflight:
456 checked, 406 compatible, 50 incompatible, zero new model runs, and the
sealed 35-task holdout. The counts are regenerated from verified `summary.json`.
