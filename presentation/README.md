# Judge Presentation

The current [3–4 minute narrated demo](demo/README.md) includes the MP4, transcript,
captions, editable HyperFrames source, and reviewed development evidence. Its
story is about keeping the human from becoming the bottleneck.

Six core slides maximum.

1. **Mini Gibson — Keep the work moving.**
   Mark and John's return to hands-on building; more generated code can create
   more coordination, checking and rescue for the human.
2. **Problem**
   Models generate code; engineers produce verified software.
3. **What we built**
   MODEL + AGENT + GIBSON ENVIRONMENT + TASK.
4. **Experiment**
   A baseline → B + Gibson → C + historical learning.
5. **Results**
   Keep the 7B pipeline/endpoint results separate from the exploratory 30B
   development counts. Do not present either as final held-out quality gains.
6. **Bigger idea**
   Can development history become accumulated experience for future coding agents?

Demo: doctor → task → natural failure/recovery → Evidence Gate → measured report.

Keep a recorded fallback trace. Never fabricate a failure or result.
