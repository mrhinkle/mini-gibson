## What still needs a run receipt

This image records environment creation. It does not show a running training
process, optimizer steps, loss values, a saved checkpoint, or completed model
evaluation. It therefore does not, by itself, establish completed training on
Brev or an improvement from fine-tuning.

To substantiate those claims, attach the corresponding run evidence:

- Run ID, source commit, model revision, dataset version, and training configuration.
- Training log with optimizer steps, loss values, and completion status.
- Saved checkpoint or adapter location and hash, plus a successful reload check.
- Separate serving and held-out evaluation receipts for any model-quality claim.

See the [training plan](../training-plan.md) and
[readiness handoff](../readiness/README.md) for the experiment sequence.
