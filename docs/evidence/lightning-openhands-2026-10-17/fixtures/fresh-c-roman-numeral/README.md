# Parse canonical Roman numerals

`parse_roman(text)` converts a canonical uppercase Roman numeral from `I` through `MMMCMXCIX` into an integer from 1 through 3999. Empty, lowercase, non-canonical, out-of-range, non-string, or otherwise malformed inputs raise `ValueError`.

Change only `roman.py`. Run `python3 -m unittest discover -s tests -q`.
