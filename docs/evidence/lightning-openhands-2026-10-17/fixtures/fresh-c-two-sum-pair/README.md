# Find the lexicographically first two-sum pair

`two_sum_pair(values, target)` returns the lexicographically smallest index pair `(i, j)` with `i < j` and `values[i] + values[j] == target`, or `None` when no pair exists. It must accept one-shot iterables and not mutate inputs. Every value and the target must be an actual integer, not a boolean; invalid inputs raise `ValueError`.

Change only `pairs.py`. Run `python3 -m unittest discover -s tests -q`.
